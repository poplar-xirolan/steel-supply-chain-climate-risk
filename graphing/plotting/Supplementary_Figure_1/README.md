# Supplementary Figure 1 — steel MFA system definition

`Supplementary_Figure_1.drawio` is the editable source for the **system-definition
diagram** in the current Supplementary Information. This is not the legacy
quantitative MFA Sankey plot. It defines process, market and stock nodes, and
the domestic, trade, recycling and boundary-flow connections between them.

## Files

- `Supplementary_Figure_1.drawio`: two consecutive, fully editable native pages.
- `reference/`: PNG and SVG exports of each restored segment, and a two-page PDF.
- `output/`: an initially empty directory for your own exports.

## Requirements and manual export

Install draw.io Desktop separately. The restored source was checked with
**draw.io Desktop 28.1.2** and **Arial** on Windows. No Python packages, model
runs, numerical input tables, external images or internet access are required.
No export utility or bundled application is supplied.

1. Open `Supplementary_Figure_1.drawio` in draw.io Desktop.
2. Select **Segment 1 - mining to steel products**, then
   **Segment 2 - manufacturing to end-of-life supply**. Both pages are part of
   Supplementary Figure 1; the second is a continuation, not a separate figure.
3. Export the complete current page, not a selection, with a white background,
   a light appearance, no grid, and a border of **16**. For PNG use **200%** zoom.
4. For SVG, include a copy of the diagram and do not embed fonts. For PDF,
   export **All Pages** and crop to the diagram. Labels may shift if a different
   application version or font is used.
5. Save your exports in `output/`. Keep `reference/` unchanged for comparison.

The native shapes, labels, arrows, break markers and legend remain editable.
There are no bitmap images in the restored source. The PNG files are preview
exports, not the editable artwork.

## Recovery scope

The supplied drawing's clean native diagram was split into the SI's two
segments. Four routes continue across the split: M4 → P6, M6 → P6, P6 → M9
(new scrap), and P7 → M9 (old scrap). The jagged break markers and the relocated
legend were recovered as native drawing objects. An isolated clipped fragment
of the Environment label in the second manuscript image was not retained.
The existing light colours were pinned and the Windows font was made explicit.

Process/market identities, node wording, material-flow directions and the
existing symbol meanings were retained. This is an editable recovery of the
current manuscript illustration, **not a pixel-identical reproduction of the
old raster/PPT assembly** and not a new numerical analysis. No manuscript or
model files were changed. Internal author notes, duplicate working views and
literature screenshots from the supplied original are not included here.

Because this is a manually authored definition diagram, it has no separate
`graphing/data/Supplementary_Figure_1/` numerical-input folder. Editing/exporting
the drawing is its reproduction workflow; no historical Sankey notebook is
needed to create it.
